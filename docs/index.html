WormholeLink

Native macOS SSH tunnel manager — right in your menu bar

↓  Download DMG All Releases View on GitHub

macOS 13 Ventura or newer  ·  Universal binary (Apple Silicon & Intel)

Features

🔀

Three tunnel types

Local forward, remote forward, and SOCKS proxy tunnels — all in one app.

🔑

Keychain credential storage

Passwords and passphrases are stored in the macOS Keychain, never in plain text.

🔁

Auto-reconnect

Tunnels reconnect automatically on disconnect with exponential back-off.

🌐

System proxy integration

SOCKS tunnels can automatically configure the macOS system proxy settings.

📋

Import & export

Share tunnel configurations as JSON — individually or as a bulk backup.

🚀

Launch at login

Start automatically and connect configured tunnels the moment you log in.

Requirements

macOS
13 Ventura or newer
Architecture
Universal binary — Apple Silicon and Intel
SSH
System SSH at /usr/bin/ssh (included with macOS)
